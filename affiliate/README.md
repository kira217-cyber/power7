# POWER7 — Affiliate

অ্যাফিলিয়েট পার্টনারদের সাইট। লেআউট ও ছন্দ BetChokkor এর অ্যাফিলিয়েট
সাইটের মতো, কিন্তু **রঙ, ফন্ট ও সব লেখা POWER7 এর ক্লায়েন্ট সাইট
থেকে** — নেভি `#010928`, বেগুনি `#AD00FF`/`#BC43F4`, সোনালি `#FBD029`,
ফন্ট Asap।

## চালানো

```bash
npm install
npm run dev        # http://localhost:5174
```

ক্লায়েন্ট সাইট চলে `5173` এ।

## পেজ

| রুট | কী |
| --- | --- |
| `/` | ল্যান্ডিং — হিরো, স্ট্যাট, কমিশন স্ল্যাব + ক্যালকুলেটর, তিন ধাপ, কেন আমরা, প্রোভাইডার, FAQ, CTA |
| `/login` | অ্যাফিলিয়েট লগইন |
| `/register` | অ্যাফিলিয়েট রেজিস্ট্রেশন |
| `/forgot-password` | পাসওয়ার্ড রিসেট (ফোন → OTP) |

সবগুলো মোবাইল, বড় ফোন, ট্যাবলেট, ল্যাপটপ ও ডেস্কটপে পরীক্ষা করা
(`scratchpad/tb/verifyaff.py` — ৫টা প্রস্থ × ৪টা পেজ)।

## ভাষা

সব লেখা `src/data/locale.js` এ **বাংলা ও ইংরেজি** দুটোতেই। হেডারের
পতাকা থেকে টগল, পছন্দ localStorage এ সেভ থাকে — ক্লায়েন্ট সাইটের মতোই।

## স্ট্যাটিক ডেটা

`src/data/affiliateData.js` — স্ট্যাট, কমিশন স্ল্যাব, ধাপ, ফিচার,
প্রোভাইডার ও FAQ।

কমিশনের সংখ্যাগুলো **power7.live এর আসল রেফারেল অফার** থেকে — হিরোর
নিচে যে "৪ টি রেফার কমিশন" ব্যানারটা আছে, তাতেই লেখা:
৳৩০৯ প্রতি রেফারেল · ০.৬৯% প্রতি ডিপোজিটে · ০.৯৭% ৩ স্তরের বাজি কমিশন ·
৳১৯,৯৯৯,৯৯৯ পর্যন্ত অর্জন বোনাস।

## server

POWER7 এর নিজের server এখনো নেই, তাই সাইটটা **স্ট্যাটিক ডেটাতেই
চলে** — `.env.local` এ `VITE_API_URL` খালি রাখা আছে। server হলে ওটা
বসালেই `globalSlice` এর thunk অ্যাডমিন থেকে পরিচয়, ফুটার, হোম ও auth
কনটেন্ট এনে স্ট্যাটিকটার উপরে বসাবে; শেপ একই থাকবে।

> `VITE_API_URL` না দিলে **কোনো API কলই হয় না** — নইলে অন্য প্রকল্পের
> server চালু থাকলে তার লোগো ও লেখা ঢুকে পড়ে।
