# POWER7 — API Server

Express 5 + Mongoose 8। অ্যাডমিন প্যানেলের (`../admin`) ব্যাকএন্ড।
চলে `localhost:5000` এ।

## চালানো

```bash
cd server
npm install
cp .env.example .env     # তারপর মান বসান
npm start                # ডেভেলপমেন্টে: npm run dev
```

`.env` কখনোই গিটে যায় না — `.gitignore` এ ব্লক করা।

## এনভায়রনমেন্ট ভেরিয়েবল

| নাম | কাজ | বাধ্যতামূলক |
| --- | --- | --- |
| `PORT` | সার্ভার পোর্ট (ডিফল্ট `5000`) | না |
| `MONGO_URI` | MongoDB কানেকশন স্ট্রিং | হ্যাঁ |
| `JWT_SECRET` | টোকেন সাইনিং কী, কমপক্ষে ৩২ অক্ষর | হ্যাঁ |
| `JWT_EXPIRE` | টোকেনের মেয়াদ (ডিফল্ট `7d`) | না |
| `CORS_ORIGINS` | অনুমোদিত অরিজিন (এখন সব খোলা) | না |
| `NODE_ENV` | `production` হলে এরর মেসেজে বিস্তারিত যায় না | না |

`JWT_SECRET` না থাকলে বা ৩২ অক্ষরের কম হলে সার্ভার চালুই হয় না — দুর্বল
সিক্রেট নিয়ে ডিপ্লয় হয়ে যাওয়া ঠেকাতে।

## ফোল্ডার

```
config/db.js                 MongoDB কানেকশন
models/Admin.js              অ্যাডমিন স্কিমা (role, permissions, লক)
middleware/protectAdmin.js   টোকেন যাচাই + রোল গার্ড
routes/adminRoutes.js        অথ ও অ্যাডমিন ব্যবস্থাপনা
routes/dashboardRoutes.js    ড্যাশবোর্ডের পরিসংখ্যান
utils/                       টোকেন জেনারেটর, রেসপন্স হেল্পার
scripts/createFirstAdmin.js  প্রথম mother অ্যাডমিন তৈরি
index.js                     অ্যাপ বুটস্ট্র্যাপ
```

## প্রথম অ্যাডমিন

ডেটাবেস খালি থাকলে একবারই চালান:

```bash
node scripts/createFirstAdmin.js <email> [password]
```

পাসওয়ার্ড না দিলে নিজে একটা শক্ত পাসওয়ার্ড বানিয়ে **একবারই** দেখায় —
ডেটাবেসে শুধু bcrypt হ্যাশ থাকে, পরে আর উদ্ধার করা যায় না। হারালে আবার
এই স্ক্রিপ্ট দিয়ে নতুন অ্যাডমিন বানাতে হবে (অথবা mother অ্যাডমিন প্যানেল
থেকে পাসওয়ার্ড রিসেট করবে)।

## রোল

| রোল | পারে |
| --- | --- |
| `mother` | সব — অ্যাডমিন তৈরি, সম্পাদনা, মুছে ফেলা |
| `sub` | শুধু যেসব পেজের `permissions` দেওয়া আছে |
| `viewer` | সব দেখে, কিছুই বদলাতে পারে না (নিজের প্রোফাইলও নয়) |

রোল যাচাই **সার্ভারেই** হয় (`middleware/protectAdmin.js`) — প্যানেলের
গার্ড শুধু UI লুকায়, নিরাপত্তা দেয় না। টোকেন এডিট করে রোল বদলালেও
API 403 দেয়।

## API

| মেথড | পাথ | কে |
| --- | --- | --- |
| POST | `/api/admin/create-first-time` | শুধু ডেটাবেস খালি থাকলে |
| GET | `/api/admin/demo-credentials` | সবাই (ডেমো অ্যাকাউন্ট থাকলে) |
| POST | `/api/admin/login` | সবাই (রেট লিমিটেড) |
| GET | `/api/admin/profile` | লগইন করা অ্যাডমিন |
| PUT | `/api/admin/profile` | লগইন করা অ্যাডমিন (viewer নয়) |
| GET/POST | `/api/admin/admins` | mother |
| PUT/DELETE | `/api/admin/admins/:id` | mother |
| GET | `/api/dashboard/summary` · `/today` | লগইন করা অ্যাডমিন |
| GET | `/health` | সবাই |

## ড্যাশবোর্ডের ডেটা

এখন ডেটাবেসে শুধু `Admin` কালেকশনটাই আছে, তাই **`Admin Accounts`
সংখ্যাটাই আসল** — বাকিগুলো ০। User, DepositRequest, WithdrawRequest
ইত্যাদি মডেল যোগ হলে `routes/dashboardRoutes.js` এ শুধু কোয়েরিগুলো
বসালেই হবে; রেসপন্সের শেপ বদলাতে হবে না, তাই প্যানেল অপরিবর্তিত থাকবে।

## লগইন পেজের ডেমো অ্যাকাউন্ট

লগইন পেজে একটা অ্যাকাউন্টের ইমেইল ও পাসওয়ার্ড কপি-বোতামসহ দেখানো
যায়। প্যানেলে **Admin Accounts → রোল `View only` → "Show on login
page"** টিক দিলেই হয়।

পাসওয়ার্ড bcrypt হ্যাশ হয়ে থাকে, হ্যাশ থেকে ফেরত আনা যায় না — তাই
দেখানোর জন্য ওই একটা অ্যাকাউন্টের পাসওয়ার্ড `demoPassword` ফিল্ডে
আলাদা করে রাখা হয় (`select: false`)। যেটা সবাইকে দেখানোই উদ্দেশ্য,
সেটা লুকিয়ে রাখার মানে হয় না।

বেড়া দেওয়া আছে যেন অন্য কারো পাসওয়ার্ড এভাবে বেরোতে না পারে:

- রোল **viewer** না হলে টিকই দেওয়া যায় না (API 400 দেয়)
- viewer থেকে রোল সরালে টিক ও রাখা পাসওয়ার্ড দুটোই মুছে যায়
- একসাথে **একটাই** অ্যাকাউন্ট দেখানো যায় — নতুনটায় টিক দিলে আগেরটা ওঠে
- পুরোনো অ্যাকাউন্টে টিক দিতে হলে একই সাথে নতুন পাসওয়ার্ডও দিতে হয়
- অ্যাকাউন্ট মুছলে, নিষ্ক্রিয় করলে বা টিক তুললে বাক্সটা নিজেই মিলিয়ে যায়

`.env` এর `DEMO_ADMIN_EMAIL`/`DEMO_ADMIN_PASSWORD` এখনো ফলব্যাক হিসেবে
কাজ করে, কিন্তু প্যানেলের টিকটাই আগে দেখা হয়।

## নিরাপত্তা

- পাসওয়ার্ড bcrypt (১২ রাউন্ড), স্কিমায় `select: false` — ভুল করেও রেসপন্সে যায় না
- পরপর ৫ বার ভুল পাসওয়ার্ড → অ্যাকাউন্ট ১৫ মিনিট লক (HTTP 423)
- **ব্যর্থ** লগইন চেষ্টা ১৫ মিনিটে সর্বোচ্চ ২০ (ডেভেলপমেন্টে ১০০) —
  হিসাব হয় IP + ইমেইল ধরে, তাই একজনের ভুল টাইপিংয়ে একই নেটওয়ার্কের
  অন্যরা আটকায় না। **সফল লগইন গোনা হয় না**, তাই বারবার ঠিকঠাক ঢুকলেও
  "Too many login attempts" আসে না। ৪২৯ এর বার্তায় কত মিনিট পরে আবার
  চেষ্টা করা যাবে সেটাও লেখা থাকে
- পুরো `/api` তে মিনিটে ৩০০ অনুরোধ
- ভুল পাসওয়ার্ড আর নেই এমন ইমেইল — একই বার্তা, তাই কোন ইমেইল আছে বোঝা যায় না
- `helmet`, বডি সাইজ ১mb
- শেষ mother অ্যাডমিন মুছে ফেলা যায় না, নিজের রোল বা স্ট্যাটাস নিজে বদলানো যায় না
